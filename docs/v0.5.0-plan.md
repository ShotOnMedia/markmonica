# MarkMonica v0.5.0

## Goal
Turn the polished guest experience from v0.4 into a stronger host-facing product without introducing billing before the product model is ready.

## Milestones

1. **Host dashboard**
   - richer event cards with cover imagery and lifecycle state
   - quick access to management and live guest page
   - improved create-event and empty states
   - event/media summary metrics

2. **Event lifecycle**
   - make upcoming/live/past state clear while keeping upload availability under explicit host control
   - surface recent guest activity

3. **Media management**
   - clearer photo/video/processing counts
   - improve bulk workflows and status visibility

4. **Archive lifecycle**
   - automatic expiry and cleanup for generated ZIP archives
   - avoid unbounded object-storage growth

5. **Product foundations**
   - account `plan_code` and event `package_code` metadata
   - package assignment timestamp on each event
   - provider-neutral package catalogue for limits and feature entitlements
   - initial `free` definition provides one place for event/media/storage/video limits and guest-gallery/archive capabilities
   - package metadata is deliberately separate from Stripe, PayFast or any other payment provider
   - v0.5 records product intent but does not yet enforce commercial limits; enforcement can be enabled once package/pricing requirements are final

## Release discipline
v0.5 work stays on `feature/v0.5.0-host-dashboard` until CI and production smoke testing pass. The v0.4.0 tag remains the rollback checkpoint.
